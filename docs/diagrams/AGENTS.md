# docs/diagrams — схемы архитектуры

Модель архитектуры SPLA и редактор, в котором её собирают: [`README_RU.md`](README_RU.md) —
что здесь лежит, [`projects/AGENTS.md`](projects/AGENTS.md) — как работать с файлами моделей,
[`TEXT-GUIDE.md`](TEXT-GUIDE.md) — что писать внутри текстов.

## Границы

- **Это самостоятельная экспериментальная фича.** Она живёт отдельно от агента и **не влияет на
  формулировки основного проекта**. Всё, что описано здесь, остаётся здесь.

- **Стек редактора не является исключением из «только .NET».** Редактор — Vue/TS, его локальный
  сервер — Go. Принцип единого языка ядра говорит о пути исполнения агента; инструментарий
  разработки к этому пути не относится и тезис не ослабляет. В корневом README формулировка
  «web-клиент — единственное осознанное исключение» остаётся как есть — не «уточнять» её из-за
  того, что найдено в этом каталоге.

- **Не тянуть внутреннюю кухню наружу.** Состояние утилит (что `tools/spla-atlas` ещё не написан,
  что `tools/spla-arch` выведен из обращения, что сверки модели с кодом пока нет) — рабочие детали
  этого каталога. Им место здесь и в README самих утилит, а не в корневом README и не в
  общих разделах про архитектуру.

- **Упоминание в корневом README — только собственным разделом.** Без перекрёстных ссылок из
  основных разделов и без оговорок вида «но есть нюанс».

## Раскладка

Раскладку схем делает **только человек руками**. Авто-layout нет и не будет; координаты в
`views/*.view.json` пишет исключительно редактор. Добавлять сущности и связи — можно и нужно,
расставлять геометрию за человека — нет.
