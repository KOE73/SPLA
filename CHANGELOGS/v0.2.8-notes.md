Changes since [v0.2.7](https://github.com/KOE73/SPLA/releases/tag/v0.2.7).
The full record is in [CHANGELOGS/v0.2.8.md](https://github.com/KOE73/SPLA/blob/main/CHANGELOGS/v0.2.8.md).

## Windows secrets use DPAPI by default

On Windows, CLI, desktop and server hosts now select DPAPI (`CurrentUser`) unless a backend is
explicitly configured. Other platforms continue to default to the file store. Invalid or unavailable
backends stop settings resolution instead of silently falling back to plaintext.

**Upgrade note:** existing plaintext stores are not migrated automatically and are not read in place
of the selected DPAPI store. Re-enter the required credentials in the selected store before use.
Development and test fixtures can explicitly select `secrets.backend: file` in machine-level
`defaults.yaml`; that choice keeps values in plaintext. Applications embedding the runtime on Windows
must register the DPAPI backend before resolving settings.

## Prompt caching for Claude through OpenRouter

Claude models through OpenRouter request prompt caching by default. Each model has a connection-settings
switch, also available as `prompt_cache: false`. Chat and spawned-run identities accompany cache
requests. The status bar displays provider-reported cache read and write token counts for the last
call; actual cache use depends on the provider and request.

## Consistent model selection for roles and chats

Roles and chats share a model picker grouped by connection. The connection stays visible in each
model label, and a configured model remains identifiable when temporarily unavailable. Spawned
agents now use the model selected by their role.

The repository's project configuration includes `builder` and `tester` roles for compact command
reports, SeMaps MCP configuration, and the project MCP port `60777`. The example roles name specific
model IDs; adjust them to the models configured on your machine.

## Architecture maps open in SeMaps

The diagram editor, its server and legacy generators have moved out of SPLA. This repository keeps
its architecture models under `docs/diagrams`. Install [SeMaps](https://github.com/KOE73/SeMaps), then
open `spla.semaps` or run `ViewArchitecture.cmd`; the project file selects port `8780`.

## Release checks

Release verification now stops immediately when dependency installation, restore, build or tests
fail. CI no longer invokes the removed in-repository diagram checker.
