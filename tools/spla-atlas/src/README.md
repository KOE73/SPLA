# src

Пусто. Здесь должны появиться пять проектов — состав, назначение и порядок работ
в [`../AGENTS.md`](../AGENTS.md) §2 и §7.

```
SplaAtlas.Model/        контракт v2: типы реестров, чтение/запись JSON
SplaAtlas.Extraction/   Roslyn: код → сущности, структурные связи, кандидаты
SplaAtlas.Sync/         сверка реестров с извлечённым, находки
SplaAtlas.Convert/      разовый конвертер v1 → v2
SplaAtlas.Cli/          точка входа, вывод отчёта
```

Порядок: `Model` → `Convert` → `Extraction` → `Sync` → `Cli`. Конвертер раньше
извлечения — он даёт живые данные, на которых видно всё остальное.
